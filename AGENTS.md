# Agent instructions

This repo is a portable Agent Skill for building a **context strategy** for Hex's AI agents.

When a task involves Hex context engineering, Threads rollout, workspace context/guides, warehouse
descriptions, endorsements, semantic models, or diagnosing wrong agent answers, **read and follow**:

```
skills/hex-context-best-practices/SKILL.md
```

It routes to two specialists in `skills/hex-context-best-practices/agents/` and supporting material in
`skills/hex-context-best-practices/references/`. Read the referenced files as needed. Before giving
step-by-step Hex UI instructions, fetch the relevant page listed in `references/hex-docs.md` so steps
stay current.
